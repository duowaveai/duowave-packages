# Как сделать персонажа для каталога

Персонаж — это пакет: папка `packages/<id>/` с файлом `manifest.json` и папкой `assets/`. Шлюз ставит пакет из
каталога («Дом» → «Пакеты»), и персонаж появляется в «Мозг» → «Персонажи». Там его выбирают, крутят регуляторы тона
и, если нужно, правят текст. Голос у персонажа необязателен: без своего голоса он говорит запасным голосом.

## 1. Папка и манифест

```
packages/captain/
  manifest.json
  assets/
    avatar.webp          512×512, WebP или PNG, до 256 КБ (SVG нельзя)
    voices/              появится на шаге 3: снимки голоса и образец
    samples/             появится на шаге 3: фразы-пробники в Opus
```

```json
{
  "schema": 1,
  "kind": "character",
  "id": "captain",
  "version": "1.0.0",
  "api": "^1",
  "title": "Капитан",
  "description": "Старый морской волк: команды коротко, байки — по случаю.",
  "runs": ["pc", "station", "stationServer"],
  "license": "CC BY-NC 4.0, некоммерчески",
  "contributes": {
    "characters": [
      {
        "id": "captain",
        "gender": "male",
        "color": "#2F5D8A",
        "avatar": "avatar.webp",
        "prompt": "Ты — Капитан, старый морской волк в умной колонке. Говоришь коротко и по-морскому: «есть», «по местам», «полный вперёд». О себе — в мужском роде. Помогаешь всерьёз, а морские словечки — приправа, не суть ответа.",
        "tones": [
          {
            "id": "salt",
            "title": "Морское",
            "default": 1,
            "options": [
              { "label": "слегка", "line": "Морских словечек — не больше одного за ответ." },
              { "label": "в меру", "line": "Морские словечки к месту, как у бывалого моряка." },
              { "label": "шторм", "line": "Говоришь только по-морскому, а сухопутное зовёшь «берегом»." }
            ]
          }
        ],
        "samples": [],
        "fallbackVoice": "piper-denis",
        "voices": {},
        "voiceOrigin": "synthetic"
      }
    ]
  }
}
```

- `id` пакета — латиница, цифры и дефис, до 32 знаков; совпадает с именем папки. Полный id персонажа в шлюзе —
  `captain:captain`.
- `version` — semver. Меняете уже опубликованный пакет — поднимайте версию.
- `gender` — `male`, `female` или `any`: от него зависят род в речи и выбор похожего запасного голоса.
- `fallbackVoice` — голос, которым персонаж говорит без своего: `piper-denis`, `piper-dmitri`, `piper-ruslan`,
  `piper-irina` (полный список — `gateway/src/models/showcase.json` в репозитории шлюза).
- `voices`, `ref`, `samples` и `voiceOrigin` заполняет `tools/design.py` на шаге 3. Руками их не пишут.

## 2. Промт и регуляторы

- **Промт** (до 4000 знаков) говорит, кто персонаж, как он говорит, в каком роде о себе и чего не делает. Помогать по
  делу и отвечать коротко он должен всегда: это голосовой помощник.
- **Не пишите «Алиса», «Яндекс» и другие марки.** Шлюз сам добавляет строку про слово, которым будят колонку, и
  правила речи: коротко, без списков и эмодзи, числа словами.
- **Регуляторы** (`tones`): 1–3 штуки, у каждого по 3 положения. Положение — одна фраза (`line`), её шлюз добавляет к
  промту. `default` — номер положения по умолчанию, считая с нуля.
- **Аватар** — своя графика: ни реальных людей, ни чужих персонажей. Исходник кладите в `art/<id>.svg` и выполните
  `node tools/avatars.mjs captain`: получится `assets/avatar.webp`.

## 3. Голос

Нужен Мак или ПК, где в шлюзе поставлена модель OmniVoice («Голос» → «Свой голос»). Скрипт запускается питоном из её
окружения:

```bash
PY=../voice-gateway-server/clone-server/runtime/omnivoice/env/bin/python
```

**Вариант А — подобрать голос по описанию.** Голос получается синтетический, ничей. Добавьте персонажа в `voices.json`:

```json
"captain": {
  "instruct": "male, elderly, low pitch",
  "reference": "Свистать всех наверх! Курс на север, ветер попутный, до берега — три часа ходу.",
  "samples": ["Есть, капитан!", "По местам стоять, с якоря сниматься.", "Шторм прошёл, можно и чаю."]
}
```

```bash
$PY tools/design.py candidates captain --count 10    # 10 вариантов голоса одной фразы
open work/captain/index.html                         # послушать, выбрать номер
$PY tools/design.py adopt captain 7                  # вариант 7 → снимки, образец, фразы, манифест
```

`instruct` — это пол (`male`, `female`), возраст (от `child` до `elderly`), высота (от `very low pitch` до `very high
pitch`) и, если нужно, `whisper` или акцент (`british accent`), всё через запятую. `reference` — фраза на 5–8 секунд
вслух: из неё снимается голос.

**Вариант Б — своим голосом или голосом диктора, который согласен.** Запишите одну фразу на 5–8 секунд в тишине,
ровно, без пауз длиннее секунды. Подойдёт телефон: m4a, mp3 или wav. Текст нужен слово в слово:

```bash
$PY tools/design.py own captain ~/Desktop/captain.m4a --text "Свистать всех наверх! Курс на север, ветер попутный." --consent
$PY tools/design.py adopt captain 1
```

`--consent` подтверждает, что голос ваш или его хозяин согласен, что голос будет в каталоге. Без этого флага скрипт
не работает. Фразы-пробники `adopt` возьмёт из `samples` в `voices.json`, если они там есть.

**Что получится в пакете в обоих вариантах:**
- `assets/voices/omnivoice.pt` (около 13 КБ) и `cosyvoice3.pt`, если эта модель стоит;
- `assets/voices/ref.wav` — образец, из которого шлюз сам снимет голос под модель, которой при сборке не было;
- `assets/samples/*.opus` — фразы-пробники;
- в манифесте сами заполнятся `voices`, `ref`, `samples` и `voiceOrigin`: `synthetic` в варианте А, `consent` в
  варианте Б.

## 4. Проверить и собрать

```bash
node tools/build.mjs --check      # проверка: поля, размеры, пути, запрещённые слова
node tools/build.mjs              # dist/: архивы .vgp, catalog.json, превью, страница каталога
python3 -m http.server 8780 --bind 127.0.0.1 -d dist
```

Шлюз с `PACKAGES_FEED_URL=http://127.0.0.1:8780/catalog.json` покажет персонажа в «Дом» → «Пакеты». Там его можно
поставить, выбрать в «Мозг» → «Персонажи» и послушать.

## 5. Отправить

Пакет попадает в каталог через нас: изменения в `packages/<id>/` и, если делали голос, в `voices.json`. Как именно
отправлять (pull request, письмо, форма), решим позже. Мы проверяем текст, картинку и голос, и только после этого
пакет выходит в каталоге с отметкой `verified`. Без проверки в каталог не попадает ничего.

Правила:
- голос синтетический или с согласия хозяина;
- никаких клонов актёров, знаменитостей и персонажей фильмов;
- лицензия — CC BY-NC 4.0, некоммерческое использование.
